# הגשה לחנות של גוגל — כל מה שצריך להדביק

> אם הדשבורד כבר מציג לך רשימת שגיאות אדומות, לך ל־[SUBMIT.md](SUBMIT.md) —
> שם כל שגיאה ממופה לכרטיסייה, לשדה ולטקסט המדויק.

## 1. החבילה

```bash
./tools/package.sh
```

מפיק `dist/keyboard-snippets-<version>.zip`. זה הקובץ שמעלים.
הסקריפט מריץ ולידציה לפני האריזה ונעצר אם משהו לא תקין.

**לפני כל העלאה חוזרת** צריך להעלות את `version` ב־`manifest.json` — החנות
דוחה חבילה עם גרסה שכבר הועלתה.

## 3. נימוקי הרשאות (Privacy practices)

**מטרה יחידה** (Single purpose):
```
הדבקת קטעי טקסט שמורים מראש לתוך שדות טקסט, באמצעות צירוף פתיחה שהמשתמש מקליד.
```

**הרשאת `storage`**:
```
לשמירת הקיצורים שהמשתמש יוצר ושל הגדרות התוסף. אין שימוש אחר.
```

**גישה לכל האתרים (host permission)**:
```
התוסף מזהה את צירוף הפתיחה בשדה הטקסט שהמשתמש מקליד בו ומדביק לתוכו את הטקסט
שנבחר. כדי שזה יעבוד בשדות שהמשתמש עובד מולם, נדרשת גישה לאתרים שהוא גולש בהם.
הקוד קורא אך ורק את הטקסט שלפני הסמן בשדה הפעיל, ורק לצורך זיהוי צירוף הפתיחה.
הטקסט אינו נשמר, אינו נאסף ואינו יוצא מהדפדפן. שדות סיסמה מוחרגים במפורש.
```

**קוד מרוחק** (Remote code): לסמן **"לא, אני לא משתמש בקוד מרוחק"**.

## 4. הצהרת שימוש בנתונים (Data usage)

לסמן **שאף קטגוריה אינה נאספת**. התוסף לא משדר שום מידע החוצה: אין בו
`fetch`, אין `XMLHttpRequest` ואין `WebSocket` (הוולידציה בודקת את זה).

שלוש ההצהרות בתחתית הטופס — לסמן את שלושתן:
- איני מוכר או מעביר נתונים לצדדים שלישיים שאינם קשורים למטרה
- איני משתמש בנתונים למטרות שאינן קשורות לתכלית התוסף
- איני משתמש בנתונים לקביעת כושר אשראי או להלוואות

## 5. תמונות — מה צריך לצלם

זה החלק היחיד שדורש עבודה ידנית.

**חובה: לפחות צילום מסך אחד, 1280×800** (או 640×400). מומלץ שלושה:

1. **התפריט פתוח באתר אמיתי** — ג'ימייל או וואטסאפ ווב, עם `//` מוקלד ורשימת
   הקיצורים גלויה. זו התמונה החשובה ביותר, שימו אותה ראשונה.
2. **האזור האישי** — עם 5-6 קיצורים ברשימה, כדי שייראה מיושב.
3. **החלונית המהירה** — לחיצה על אייקון התוסף.

טיפ: הגדילו את הדפדפן ל־1280 רוחב וצלמו חלון, לא מסך מלא.
אל תשאירו בצילום מידע אישי אמיתי — שמות לקוחות, מספרי טלפון או תוכן הודעות.

**סמל החנות** (חובה): `store/icon-128.png` — יוצר במיוחד להגשה, 128×128 עם
ציור 96×96 ממורכז ושוליים שקופים לפי ההנחיה של גוגל. אל תעלה את
`icons/icon128.png`, שממלא את כל המסגרת ונראה גדול מדי בחנות.

**אופציונלי**: אריח קידום קטן 440×280. משפר את התצוגה בחנות, לא חוסם הגשה.

## מה לצפות

הבדיקה נמשכת בדרך כלל בין יום לשבוע. גישה לכל האתרים מאריכה אותה —
זה תקין ולא סימן לבעיה. אם מגיעה דחייה, היא תמיד מציינת את סעיף המדיניות
המדויק; ברוב המקרים מדובר בניסוח נימוק ההרשאות ולא בקוד עצמו.
