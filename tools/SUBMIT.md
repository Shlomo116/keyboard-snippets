# פתרון 12 השגיאות בטופס ההגשה

כל השגיאות הן שדות בטופס של הדשבורד — אף אחת מהן אינה בעיה בקוד.
המסמך הזה ממפה כל שורה אדומה לכרטיסייה, לשדה ולטקסט המדויק להדבקה.

הדשבורד: https://chrome.google.com/webstore/devconsole

---

## שגיאה 9 + 10 — כתובת אימייל ואימות שלה

> "צריך לספק כתובת אימייל ליצירת קשר… צריך לאמת את כתובת האימייל"

**תתחיל מכאן.** האימות לוקח כמה דקות (מייל אישור), וכל השאר מחכה לו.

גלגל השיניים **הגדרות** (למעלה מימין, מחוץ לפריט) ← לשונית **פרטי חשבון** ←
שדה **אימייל ליצירת קשר** ← הזן כתובת ← **אימות** ← אשר את המייל שנשלח.

> זו הכתובת שתוצג בציבור בדף התוסף. אם אתה לא רוצה לחשוף כתובת אישית,
> פתח כתובת ייעודית לפני כן.

## שגיאה 1 — תיאור מפורט

כרטיסייה **פרטי הפריט** ← **תיאור**. להדביק כמו שהוא:

```
מקלידים את אותם משפטים עשרות פעמים ביום? התוסף הזה הופך כל הודעה חוזרת לקיצור בן מילה אחת.

איך זה עובד
הקלידו // בכל שדה טקסט באינטרנט — נפתח תפריט עם כל ההודעות המוכנות שלכם.
המשיכו להקליד כדי לסנן: //ברוכ ימצא את //ברוכים-הבאים.
בחרו עם Enter או בעכבר, והטקסט המלא נכנס במקום.

ניווט
חצים למעלה ולמטה לניווט, Enter או Tab לבחירה, Esc לביטול.

חיפוש חכם
החיפוש מוצא גם כשלא זוכרים את השם המדויק — //פטים ימצא את //פרטים.
קיצורים שאתם משתמשים בהם יותר עולים אוטומטית לראש הרשימה.

סנכרון בין מכשירים
הקיצורים מגיעים לכל מכשיר שמחובר לאותו חשבון Google בכרום. בלי הרשמה ובלי חשבון נוסף.

עובד כמעט בכל מקום
ג'ימייל, וואטסאפ ווב, לינקדאין, מערכות CRM, טפסים ותיבות חיפוש.
תמיכה מלאה בעברית ובכיווניות RTL.

האתר תופס את הסלאש לעצמו?
אפשר להחליף את צירוף הפתיחה ל-;; או :: או .. בלחיצה אחת.

פרטיות
אין שרת, אין מעקב, אין איסוף נתונים. הקיצורים נשמרים באחסון של כרום בלבד,
והתוסף לא מבצע שום קריאת רשת. שדות סיסמה מוחרגים לחלוטין.

התוסף חינמי וקוד פתוח:
https://github.com/Shlomo116/keyboard-snippets
```

## שגיאה 12 — תמונת הסמל חסרה

כרטיסייה **פרטי הפריט** ← **סמל החנות** ← העלה את הקובץ:

```
store/icon-128.png
```

יוצר במיוחד להגשה: 128×128, עם ציור 96×96 ממורכז ושוליים שקופים,
לפי ההנחיה של גוגל. אל תעלה את `icons/icon128.png` — הוא ממלא את כל
המסגרת ונראה גדול מדי ליד סמלים אחרים בחנות.

## שגיאה 7 — צילומי מסך

כרטיסייה **פרטי הפריט** ← **צילומי מסך**. נדרש **אחד לפחות**, בגודל
**1280×800** (או 640×400), PNG או JPEG.

זה החלק היחיד שדורש עבודה ידנית. המתכון המהיר:

1. הגדר את חלון כרום לרוחב 1280.
2. **צילום 1 (החשוב ביותר, שים אותו ראשון)** — פתח ג'ימייל או וואטסאפ ווב,
   הקלד `//` בשדה ההודעה, וצלם את החלון כשהתפריט פתוח.
3. **צילום 2** — האזור האישי, עם 5-6 קיצורים ברשימה כדי שייראה מיושב.
4. **צילום 3** — החלונית המהירה, בלחיצה על אייקון התוסף.

במק: `Cmd+Shift+4` ואז מקש רווח לצילום חלון בודד.

> ⚠️ עבור על הצילומים לפני ההעלאה וּודא שאין בהם מידע אישי אמיתי —
> שמות לקוחות, מספרי טלפון, כתובות מייל או תוכן הודעות. זו הטעות הכי
> קלה לעשות עם תוסף שכל כולו טקסטים אמיתיים.

## שגיאות 3 + 4 + 5 + 6 + 8 — כרטיסיית "נוהלי פרטיות"

כל החמש יושבות באותה כרטיסייה: **נוהלי פרטיות** (Privacy practices).

### שגיאה 6 — מטרה יחידה

```
הדבקת קטעי טקסט שמורים מראש לתוך שדות טקסט, באמצעות צירוף פתיחה שהמשתמש מקליד.
```

### שגיאה 3 — נימוק להרשאת storage

```
לשמירת הקיצורים שהמשתמש יוצר ושל הגדרות התוסף, באחסון של כרום. אין שימוש אחר.
```

### שגיאה 4 — נימוק להרשאת מארח (גישה לאתרים)

```
התוסף מזהה את צירוף הפתיחה בשדה הטקסט שהמשתמש מקליד בו, ומדביק לתוכו את הטקסט
שנבחר. כדי שזה יעבוד בשדות שהמשתמש עובד מולם, נדרשת גישה לאתרים שהוא גולש בהם.
הקוד קורא אך ורק את הטקסט שלפני הסמן בשדה הפעיל, ורק לצורך זיהוי צירוף הפתיחה.
הטקסט אינו נשמר, אינו נאסף ואינו יוצא מהדפדפן. שדות סיסמה מוחרגים במפורש.
```

### שגיאה 5 — שימוש בקוד מרוחק

בחר **"לא, אני לא משתמש בקוד מרוחק"**.

זו התשובה הנכונה: כל הקוד ארוז בתוך החבילה. אין `fetch`, אין `XMLHttpRequest`,
אין `WebSocket`, אין `eval` ואין טעינת סקריפט חיצוני — הוולידציה בודקת את זה
בכל אריזה. אם השדה דורש הסבר:

```
כל קוד התוסף כלול בחבילה. התוסף אינו טוען, מוריד או מריץ קוד ממקור חיצוני.
```

### הצהרת שימוש בנתונים

באותה כרטיסייה, לסמן **שאף קטגוריה של נתונים אינה נאספת**.

### שגיאה 8 — אישור עמידה במדיניות

בתחתית הכרטיסייה, לסמן את שלוש ההצהרות:

- איני משתמש בנתונים למטרות שאינן קשורות לתכלית התוסף
- איני משתמש בנתונים לקביעת כושר אשראי או להלוואות

5. **שמירה כטיוטה** ← לוודא שכל האדום נעלם ← **שליחה לבדיקה**
