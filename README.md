# קיצורי הקלדה — תוסף כרום

<div dir="rtl">

תוסף שמאפשר להדביק הודעות חוזרות בכל שדה טקסט בדפדפן, על ידי הקלדת שני סלאשים (`//`) ואז חיפוש חופשי.
מיועד לצוותי תמיכה, שירות ומכירות שמקלידים את אותם משפטים עשרות פעמים ביום.

## התקנה

התוסף אינו בחנות — מתקינים אותו במצב מפתח:

1. הורדה: `git clone https://github.com/Shlomo116/keyboard-snippets.git`
   (או Code ← Download ZIP ← חילוץ)
2. פתיחת `chrome://extensions` בכרום
3. הפעלת **מצב מפתח** (Developer mode) בפינה
4. **טעינת פריט לא ארוז** (Load unpacked) ← בחירת תיקיית הפרויקט
5. נעיצת התוסף לסרגל הכלים (אייקון הפאזל ← נעיצה)

לשוניות שכבר היו פתוחות צריכות רענון כדי שסקריפט התוכן ייטען בהן.

## שימוש

**הוספת קיצור** — לחיצה על אייקון התוסף מאפשרת הוספה מהירה, או מעבר ל**אזור האישי** לניהול מלא.
כל קיצור מורכב מכותרת **ללא רווחים** (רווחים מומרים אוטומטית ל־`-`) ומתוכן ההודעה.

**החלפת צירוף הפתיחה** — יש אתרים שתופסים `/` לתפריט משלהם (וואטסאפ ווב, Notion, Slack).
באזור האישי, למעלה, אפשר להחליף את צירוף הפתיחה ל־`;;`, `::`, `..`, `,,` או `\\`.
ההחלפה חלה מיד בכל הלשוניות.

**שימוש בקיצור** — בכל שדה טקסט באתר כלשהו:

| פעולה | מקש |
|---|---|
| פתיחת התפריט | הקלדת `//` (או הצירוף שבחרתם) |
| סינון | המשך הקלדה (`//ברוכ` ימצא את `//ברוכים-הבאים`) |
| ניווט | `↑` `↓` · `Home` · `End` |
| בחירה | `Enter` · `Tab` · לחיצה בעכבר |
| ביטול | `Esc` |

הטקסט הנבחר מחליף את ה־`//` ואת כל מה שהוקלד אחריו.

### החיפוש

הדירוג מתחשב בסדר הבא: התאמה מדויקת לכותרת ← תחילת הכותרת ← הכלה בכותרת ←
אותיות לפי הסדר (fuzzy — `//פטים` ימצא את `//פרטים`) ← הכלה בתוכן ההודעה.
בתוך כל רמה, קיצורים שנעשה בהם יותר שימוש עולים למעלה.

## איפה זה עובד

עובד בשדות `input` (מסוג `text`, `search`, `url`, `tel`), ב־`textarea` ובאזורי `contenteditable`
(ג'ימייל, וואטסאפ ווב, לינקדאין, Notion וכדומה), כולל בתוך `iframe`.

מוחרגים בכוונה:
- שדות סיסמה, שדות לקריאה בלבד ושדות מושבתים
- `input type="email"` ו־`type="number"` — כרום לא מאפשר שליטה בסמן בשדות האלה
- כתובות אינטרנט: `https://` לא מפעיל את התפריט

## פרטיות

הכול נשמר מקומית ב־`chrome.storage.local`. אין שרת, אין ניתוח, אין שליחת נתונים לשום מקום.
ההרשאה היחידה שהתוסף מבקש היא `storage`.

באזור האישי יש **ייצוא וייבוא JSON** — כרגע להעברה בין מחשבים, ובהמשך נקודת המעבר למאגר צוותי משותף.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף (Manifest V3) |
| `src/content.js` | זיהוי ה־`//`, תפריט החיפוש, ההדבקה לשדה |
| `src/options.html/.css/.js` | האזור האישי — ניהול, מיון, שכפול, ייצוא/ייבוא |
| `src/popup.html/.js` | חלונית מהירה מסרגל הכלים |
| `test-page.html` | דף בדיקה ידנית לכל סוגי השדות |

## אבחון

אם באתר מסוים התפריט לא נפתח, פתחו את הקונסולה של הדף (F12), הריצו:

```js
localStorage.snippetsDebug = 1
```

ורעננו. מעכשיו כל הקלדה תדפיס לקונסולה מה זוהה — הטקסט שלפני הסמן, האם הטריגר
נתפס, ובאיזה מסלול בוצעה ההדבקה. לכיבוי: `delete localStorage.snippetsDebug`.

### הערות מימוש

- **בידוד מהדף**: התפריט חי ב־Shadow DOM סגור, כך שעיצוב האתר המארח לא משפיע עליו ולהפך.
- **תאימות לעורכי framework**: עורכים כמו Lexical (וואטסאפ ווב), ProseMirror ו־Draft מפצלים
  טקסט בין הרבה `span`־ים, כך שה־`//` והמילה שאחריו יושבים בצמתים שונים. לכן הטקסט שלפני
  הסמן נאסף בהליכה על בלוק התוכן ולא מתוך צומת בודד, וההדבקה מוחקת את הטריגר דרך
  `Selection.modify` — הדרך היחידה שחוצה נכון גבולות צמתים. המסלול הראשי בכל סוגי השדות הוא
  `execCommand('insertText')`, ששומר על Undo של הדפדפן ומייצר את אותם אירועים שהקלדה אמיתית
  מייצרת, עם מסלולי גיבוי (native value setter ו־DOM ידני) אם הוא נכשל.
- **קדימות במקלדת**: מאזין ה־`keydown` יושב על `window` בשלב ה־capture והתוסף רץ ב־
  `document_start`, כדי להקדים אתרים שתופסים `Enter` בעצמם (וואטסאפ שולח הודעה ב־Enter).
- **RTL**: התפריט יורש את כיוון הכתיבה של השדה שבו מקלידים, ונצמד לסמן בקצה הנכון —
  ב־RTL הקצה הימני, ב־LTR השמאלי.
- **תווים בלתי־נראים**: עורכים עשירים שותלים תווי אפס־רוחב וסימני כיווניות (`U+200B`,
  `U+200E/200F`) בתוך הטקסט, בעיקר בהקשר RTL. `\s` לא תופס אותם, ולכן תו אחד כזה לפני
  הצירוף היה מפיל את הזיהוי. הם מומרים לרווח לפני ההתאמה — מומרים ולא נמחקים, כדי לשמור
  על אורך הטקסט שכל חישובי המיקום נשענים עליו.
- **ביצועים**: אינדקס חיפוש מוכן מראש (בלי `toLowerCase` בכל הקשה), בניית DOM רק כשהרשימה
  באמת משתנה, מיקום מחדש מווסת ב־`requestAnimationFrame`, ו־mirror div ממוחזר למדידת מיקום הסמן.

## בדיקות

```bash
node --check src/content.js && node --check src/options.js && node --check src/popup.js
```

לבדיקה ידנית: פתחו את `test-page.html` בכרום אחרי ההתקנה.
